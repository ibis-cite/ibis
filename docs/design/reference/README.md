# Reference design

Board M from prototype round eight: the picker as designed, in light and dark, on macOS, Windows and GNOME. All data is synthetic.

Use these images as the visual target for proportions, spacing, the header, rows, selection and the footer. Behaviour comes from [design.md](../../design.md) and [system.md](../system.md). Where the look of main and these images disagree, and no decision on the tracking issue covers it, follow the images and update the spec in the same pull request.

Not in scope for 0.2, although drawn here: the filter tabs (All, Recently cited, Recently added, With PDF), the library menu under the search box, the attachment icon in rows and the tip in the footer status.

Decisions made since round eight, which win over the images:

- The footer status shows the library name and reference count.
- The citation shelf sits above the footer once a reference is highlighted.
- The format menu is a filled pop-up button, with a clear button before it while there is a query.
