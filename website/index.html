An open-source work in progress.

Find references. Copy citation keys.

For the moment between an idea and its source.

Ibis is a small, free app for finding references in Zotero or a BibTeX file. A quick route from your library to the place you write, on Windows, macOS and Linux.

Still an early preview. I’m building Ibis in public. There are bugs and rough edges, and your experience can help decide what comes next.

Start with @how, explore the @roadmap, or @shape what Ibis becomes.

@how

From your library to your sentence

A citation key is a short label for a reference, such as rivera2025. Tools like Pandoc, LaTeX and Typst use it to find the full reference.

In today’s preview, Ibis copies the citation and you paste it. Automatic insertion into the app you’re writing in is planned.

Ibis can also copy a formatted citation in APA, Chicago, Harvard, IEEE or MLA. It does not generate your document’s bibliography.

@setup

A few first steps

Install on a Mac

Open the DMG, drag Ibis to Applications, then open it. If macOS cannot check the app, confirm it came from this project’s GitHub release, then use System Settings → Privacy & Security → Open Anyway.

Install on Windows

Run the installer. If SmartScreen warns you, check the download came from this project’s GitHub release; if you trust it and “More info → Run anyway” is offered, you can continue. Smart App Control may block it without that option. Keep protection enabled and wait for a trusted, signed build. On a work or school computer, ask IT. A missing WebView2 Runtime needs a one-time download during installation.

Install on Linux

Allow the AppImage to run as a program in its file properties, then open it. Some systems need FUSE support; see the runtime requirements on GitHub. On Wayland, open Ibis from your app launcher; its shortcut is not available yet.

Connect Zotero or a BibTeX file

Keep Zotero open. In Zotero, go to Settings → Advanced and tick “Allow other applications on this computer to communicate with Zotero”. Choose Zotero in Ibis. Or choose a BibTeX/BibLaTeX file ending in .bib. Better BibTeX can keep that export up to date; export instructions are on GitHub.

Once set up, type an author, title or year. Use the arrow keys to choose a reference and Enter to copy it. Paste it into your document. On Windows and Linux X11 the default shortcut is Ctrl+Shift+Y; on macOS it is Control+Command+R, when available.

Ibis reads your library without changing it. Searching and copying work offline after setup; update checks are opt-in. App privacy details on GitHub.

@roadmap

A small start, with room to grow

A better preview
Easier setup, accessibility and reliability. Fix the rough edges before sharing Ibis widely.
Fewer interruptions
Automatic insertion into the app you’re writing in, with copying as a fallback. Planned; the current preview still needs you to paste.
More ways to work
More citation styles, richer previews and access to Zotero while it is closed. These are plans, not features in today’s preview.

Plans can change as I learn from your feedback. Follow the full roadmap on GitHub.

@why

A reference within reach

I want finding a reference to feel quick and ordinary, wherever you write. Your library and your writing tools should be able to work together without getting in the way of the sentence.

That’s the direction for Ibis: fast, open source and across platforms, with room to connect more tools over time. The preview is a beginning. I’d like to build the rest with the people who use it.
